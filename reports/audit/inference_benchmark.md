# CPU Inference Latency Benchmark Report

This document reports the performance characteristics of model inferences executed on local CPU architectures.

## Benchmark Configuration
- **Model Evaluated**: `XGBOOST`
- **Processor Context**: CPU Execution (Single Sample Inference)
- **Warmup Iterations**: 100
- **Evaluation Loop Count**: 1000 runs

## Latency Statistics
- **Mean Inference Time**: `1.04095 ms`
- **Standard Deviation**: `0.46481 ms`
- **95th Percentile (P95)**: `1.99703 ms`
- **99th Percentile (P99)**: `2.03589 ms`
